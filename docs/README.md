# Документы Fidespipe

Порядок здесь — по тому, зачем ты открываешь документацию, а не по дате
создания. Половина файлов здесь — про устройство проекта, и их полезно читать
не подряд, а по надобности.

## Если хочешь им пользоваться

- **[Быстрый старт](quickstart.md)** — 5 минут, одна проверка, без ключей и
  без сети.
- **[Импорт своего инструмента](import.md)** — разобрать чужой Python-проект в
  готовый плагин.
- **[Плагин: как написать свой](plugin-dev.md)** — контракт, манифест, доноры,
  тесты.
- **[Продолжение прогона](resume.md)** — как продолжить цепочку с места обрыва.
- **[Развёртывание](deployment.md)** — Docker и systemd.
- **[MCP](mcp.md)** — агент как один из способов пользоваться: те же проверки
  и тот же гейт.

## Если тебе интересно, как оно устроено

- **[Архитектура](architecture.md)** — из чего собрано и почему так.
- **[Формат пайплайна и совместимость](format-compatibility.md)** — что можно

- **[Версионирование](versioning.md)** — три независимые шкалы версий.
